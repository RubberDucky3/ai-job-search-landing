# Social Media Image Dimensions

## Twitter / X
- Main post image: 1200 x 675 px (16:9)
- Profile photo: 400 x 400 px
- Header image: 1500 x 500 px

## Reddit
- Post image (in post): 1200 x 675 px (16:9)
- Banner: 2560 x 400 px

## LinkedIn
- Post image: 1200 x 627 px (1.91:1)
- Profile photo: 400 x 400 px
- Cover photo: 1584 x 396 px

## Instagram
- Post (square): 1080 x 1080 px (1:1)
- Post (portrait): 1080 x 1350 px (4:5)
- Story: 1080 x 1920 px (9:16)

## Hacker News
- No image support in posts (text only)

## Open Graph (for link previews)
- 1200 x 630 px (1.91:1)
- This is what shows when someone shares your link

## Favicon
- 32 x 32 px (PNG)
- 180 x 180 px (Apple Touch Icon)
