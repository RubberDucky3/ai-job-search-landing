# Social Media Assets

This directory contains AI image generation prompts for social media assets.
To generate the actual images, copy any prompt below into your preferred AI image tool:

- **Gemini**: https://gemini.google.com/app
- **DALL-E**: https://openai.com/dall-e
- **Midjourney**: https://midjourney.com
- **Leonardo**: https://leonardo.ai

## File Structure
```
assets/social/
├── README.md          # This file
├── prompts/           # Text prompts for image generation
│   ├── twitter-header.md
│   ├── reddit-post-image.md
│   ├── linkedin-post.md
│   ├── instagram-story.md
│   └── favicon-og.md
├── templates/         # HTML/SVG templates for programmatic generation
│   └── og-image.svg   # Open Graph image template
└── dimensions.md      # Size specifications for each platform
```
